# Install in two steps:

#   pip install -r requirements.txt
#   pip install --no-deps rtdl==0.0.9 libzero==0.0.8

# Why rtdl and libzero are installed with --no-deps:
#   Both declare "torch<2" in their metadata, but the reported experiments
#   were run against torch 2.8.0, with which both work fine. Installing them
#   with --no-deps keeps the torch version actually used for the experiments
#   instead of downgrading to torch 1.x. Their own dependencies (numpy,
#   pynvml, tqdm) are pinned explicitly below, so nothing is left unresolved.
#
# GPU note:
#   torch is pinned here to the build resolved by the default PyPI index.
#   The experiments used the cu128 build (torch 2.8.0+cu128). For a specific
#   CUDA toolkit, install torch first from
#   https://pytorch.org/get-started/locally/ and then run this file.
